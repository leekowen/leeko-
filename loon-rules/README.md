## 使用说明

- `stitch.list` 使用 `PROXY` 作为策略名；导入前请确保 Loon 配置中存在同名策略或策略组。
- 规则只包含 `stitch.withgoogle.com`，避免影响其他 Google 服务。
- 规则文件为公开内容，请勿在其中提交令牌、订阅链接、个人账号或其他敏感信息。

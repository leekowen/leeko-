## 使用说明

- 规则不预设策略名称，导入后可按自己的配置指定策略。
- `stitch.list` 仅包含 `stitch.withgoogle.com`；`Chery.list` 匹配 `chery.com` 及其子域名。
- 规则文件为公开内容，请勿在其中提交令牌、订阅链接、个人账号或其他敏感信息。
